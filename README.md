# 8-bit breadboard CPU

> A hands-on project to understand how a CPU works by building an 8-bit CPU using breadboards and digital logic circuits.

## Overview

This project is my attempt to build an **8-bit CPU on breadboards** and understand how its different parts work together to execute operations.

The project is primarily based on **Ben Eater's 8-bit computer** and his video series. I am following his architecture and implementation as my main reference while building the CPU, while also focusing on understanding **why each component is used and why the circuits are connected in a particular way**.

The project is being developed module by module, with detailed documentation added separately as I build and understand each part.

---

## Motivation

During my first year of Electronics Engineering, I explored different areas of electronics and became particularly interested in **CPUs**.

During the vacation between my first and second year, I started looking for a hands-on project and came across the idea of building a **breadboard CPU**. The idea of physically building a CPU from individual digital circuits was fascinating to me, so I decided to take on the project.

I started this project in **June 2026**.

---

## Project Goals

The main goal of this project is to understand the internal operation of a CPU through hands-on implementation.

I want to understand:

- How a CPU executes operations
- How registers store and transfer data
- How buses allow different parts of the CPU to communicate
- How the ALU performs arithmetic and logical operations
- How RAM interacts with the processor
- How control logic coordinates the different components
- How clock and timing signals control CPU operations
- How all these parts work together as a complete CPU

The objective is not only to build a working CPU, but to **genuinely understand what is happening inside each part of the system**.
